# CareerNest 🚀
### Build Your Career, One Opportunity at a Time.

CareerNest is a full-stack web application designed to help students organize and track their internship applications in one place. It allows users to manage application details, monitor recruitment progress, keep track of deadlines, and stay organized throughout their career journey.

## ✨ Features

- **User Authentication:** Register and log in to your account.
- **Personalized Dashboard:** View application statistics and recent activity.
- **Internship Management:** Add, view, edit, and delete internship applications.
- **Application Tracking:** Track applications through Applied, Assessment, Interview, Offer, and Rejected statuses.
- **Deadline Management:** Keep track of upcoming and overdue deadlines.
- **Search and Filtering:** Find applications by company, role, or status.
- **Application Details:** Store company names, job roles, application links, locations, dates, and notes.
- **Responsive Design:** Access the application through desktop, tablet, and mobile browsers.

## 🔄 How CareerNest Works

1. Users register for an account and log in.
2. They add internship applications with company details, roles, and deadlines.
3. The frontend sends API requests to the backend.
4. The backend validates requests and stores application data in MongoDB.
5. The dashboard displays saved applications and their current statuses.
6. Users update application details, filter opportunities, and monitor deadlines.

## 🎯 Project Objective

The main objective of CareerNest is to simplify internship application management by providing students with a centralized platform to organize opportunities, monitor recruitment progress, and avoid missing important deadlines.
